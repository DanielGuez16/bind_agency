Règles du back office
Une file se traite au clavier, du haut vers le bas, et se vide : le tri par défaut est l'ancienneté pour les comptes, l'échéance pour les contreparties, l'impact utilisateur pour les jobs. Toute décision qui atteint un utilisateur exige un motif choisi dans une liste fermée, plus une note libre optionnelle qui sera lue telle quelle. Une action de masse n'est permise que sur les approbations et les relances de jobs, jamais sur un arbitrage ni sur un rejet. ⌘Z annule pendant 30 secondes, ensuite la notification est partie. Chaque écran affiche sa fraîcheur de données et bloque les décisions plutôt que d'agir sur des données périmées. Les montants n'apparaissent que dans les plans d'abonnement. Aucune illustration, aucun graphique décoratif : une colonne de chiffres se lit plus vite qu'une courbe.
